# 知衡 App 前端

Vue 3 + TypeScript + uni-app 手机端工程，对接同级 `backend` 中的 Java 服务。五个主要入口为“今日、计划、助手、趋势、我的”。

第一次使用 VS Code，请先阅读 **[VS Code 运行与 App 打包指南](VSCode运行与APP打包指南.md)**，包含环境准备、逐步启动、连接后端、手机浏览器访问及常见问题。

## 本地运行

前端默认只连接真实 Java 后端。先按 [后端启动说明](../backend/README.md) 初始化 MySQL 并启动后端 `8080`，再启动前端；两个进程都需要保持运行。

本机前端依赖已经安装。缺少依赖或换电脑时，先执行 `npm.cmd ci`。

```powershell
Set-Location -LiteralPath 'E:\new项目\frontend'
npm.cmd run dev:h5
```

打开 [http://localhost:5173](http://localhost:5173)，通过“登录 / 注册”进入账号。账号中的记录、计划与趋势均通过后端读取和保存；新账号的数据从空白开始。停止前端服务按 `Ctrl + C`。

## 连接后端

浏览器开发环境默认把 `/api` 代理到 `http://127.0.0.1:8080`。需要更换目标时，复制 `.env.example` 为 `.env.local`，修改 `VITE_PROXY_TARGET`，保持 `VITE_API_BASE_URL` 为空并重启开发服务。

独立 App 安装版需要配置手机实际可访问的服务器根地址；不包含电脑开发代理。界面“我的 → 设置”中保存的地址优先于环境变量。

后端的数据库、验证码发送、政策文档和 AI 模型配置，见 [后端 README](../backend/README.md)。前端不保存模型密钥，也没有默认用户账号。

## 本地开发注册

后端默认使用 `local` profile 与 `DEV` 环境，验证码发送方式为 `CONSOLE`，无需配置 SMTP。注册步骤：

1. 前后端同时运行，在前端切换到“注册”，填写邮箱和至少 12 位密码。
2. 点击“获取验证码”。
3. 查看运行 Java 后端的终端，找到 `[LOCAL-VERIFICATION]` 日志，将 `code=` 后的六位数字复制到前端验证码框。验证码不在浏览器控制台，也不会通过接口直接返回。
4. 打开并阅读完整服务说明，确认同意当前版本，并确认已年满 18 周岁。
5. 点击“创建账号”，按页面结果继续使用。

本地服务说明由后端 `/api/v1/development/policies/service` 返回真实 JSON，前端负责渲染，当前默认版本为 `local-service-v1`。本地专用注册配置无需修改数据库种子中的注册开关；显式设置 `ZH_REGISTRATION_ENABLED=false` 仍会关闭注册。

以上便利配置仅适用于 `local + DEV`。其他环境使用 `SMTP` 并完成邮件与正式服务说明配置，`prod` 禁止 `CONSOLE`。

## 功能与当前边界

- 生活记录：睡眠、活动、饮食、精力，新增、编辑、筛选、删除和恢复。
- 计划任务：创建草稿、冲突预览、确认激活、版本与任务操作。
- 智能助手：真实运行状态、对话、计划与记录草稿，经确认后应用。
- 趋势回顾：记录覆盖、时间范围图表、周回顾及可追溯依据。
- 账号与个人设置：注册登录、档案、目标、可用时间、分用途授权、隐私任务和反馈。

页面统一使用后端数据，连接失败或接口返回错误时显示实际错误，不填充本地记录或生成成功结果。登录令牌和健康内容不写入明文持久缓存，刷新页面或重启进程后需重新登录。当前未实现持久离线写入队列。

手机系统通知 SDK、手表适配、附件上传编辑界面及原生安全凭据持久化尚未接入。鸿蒙配置和编译入口已保留，实际平台签名、安装和真机测试需补齐。AppID 尚未填写，工程不包含团队签名证书，也未生成可发行的 APK / HAP。

## 检查与构建

```powershell
npm.cmd run type-check
npm.cmd test
npm.cmd run build:h5
```

网页产物位于 `dist/build/h5`。`npm.cmd run build:app` 用于生成 App 编译资源，不能直接当成手机安装包；详见操作指南。

工程依赖版本已经锁定。已验证的 Node.js 版本为 22.13.1。运行配置和构建结果以当前工程及实际日志为准。

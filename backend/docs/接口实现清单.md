## 实现约定补充

- 规划中的请求、响应模型在本次实现中按模块归并到 `resource/*/*Dtos.java` 和 `*Views.java`；字段以源代码和联调示例为准。
- 后台路由使用独立前缀，权限码和 ADMIN audience 同时检查。
- 账户注册新增落库条款版本与服务端确认时间，首次安装报告实际平台。
- 提醒以 IN_APP 为可演示送达路径；LOCAL_SYSTEM 需要安装端实现，平台 DELIVERED 回调适配器当前关闭。
- SSE 返回可恢复运行状态事件，不是逐 token 模型直通流。
- 当前私有存储适配器是加密本地磁盘，尚无云对象存储适配器。
- 数据同步/业务幂等不自动按时间压缩；初始化租约、代际隔离和显式隐私清理已实现。
